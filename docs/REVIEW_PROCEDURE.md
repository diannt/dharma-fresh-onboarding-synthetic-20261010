# Synthetic PR review procedure
Procedure ID: synthetic-envelope-review-v1
1. Read the exact PR diff and the approved envelope definition.
2. Identify the relevant rule and source reference for each finding.
3. Run the deterministic checks and retain their result.
4. Ask the other approved endpoint which counts the envelope permits.
5. Cite the correlated peer answer and demonstrate how it affected the review.
6. Report the finding with file, trigger, consequence and a concrete correction.
For the planned synthetic PR, removing the integer check admits fractional
counts and must produce a review finding grounded in ENVELOPE_RULES.md.
A stored skill, queued peer question or installed package is not proof of use.
